# Landing Page - React

## Descripción

Este proyecto consiste en una Landing Page desarrollada con React utilizando Vite como herramienta de construcción. La aplicación presenta una interfaz moderna y responsive que incluye navegación, secciones informativas y un formulario de registro con validaciones en el lado del cliente.

## Tecnologías utilizadas

* React
* Vite
* JavaScript
* HTML5
* CSS3

## Características

* Diseño responsive adaptable a dispositivos móviles y escritorio.
* Arquitectura basada en componentes reutilizables.
* Navegación entre secciones mediante enlaces internos.
* Formulario de registro con validaciones frontend.
* Interfaz amigable y organizada.

## Componentes implementados

* Header
* Hero
* Features
* Registro
* Footer

## Validaciones del formulario

* Nombre: solo permite letras y espacios.
* Correo electrónico: formato válido de email.
* Edad: debe ser mayor o igual a 18 años.
* Contraseña: exactamente 10 caracteres incluyendo letras, números y un símbolo.
* Género: selección obligatoria.
* Términos y condiciones: aceptación obligatoria.

## Ejecución local

Instalar dependencias:

npm install

Iniciar servidor de desarrollo:

npm run dev

Generar versión de producción:

npm run build
